# Sabores da Prata — site institucional

Protótipo estático (HTML/CSS/JS puro, sem build) para apresentar ao cliente.

## Antes de publicar
1. **WhatsApp**: edite `script.js`, troque `WHATSAPP_NUMBER` pelo número real (55 + DDD + número).
2. **Endereço e horários**: edite a seção `#local` em `index.html`.
3. **Mapa**: troque a busca no `src` do iframe pelo endereço real (ou pelo link "Compartilhar > Incorporar mapa" do Google Maps).
4. **Fotos**: as caixas de produtos usam ícones no lugar de fotos reais — crie uma pasta `images/` e troque os `<svg>` por `<img>` com as fotos do produto.
5. **Depoimentos**: troque os textos de exemplo pelas avaliações reais copiadas do Google Maps.

## Publicar no GitHub Pages
1. Crie um repositório e suba os arquivos (`index.html`, `style.css`, `script.js`).
2. Em *Settings > Pages*, selecione a branch `main` e a pasta raiz.
3. O site fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
